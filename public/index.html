Interview Helper

On macOS, screen capture happens from the native menu bar app (make mac-app), not this page. The app is standalone and does not use this server.

Desktop (Mac)

Menu bar IH → Capture & Analyze, or press ⌥⇧S.

Grant Screen Recording permission for the native app on first run.

Viewer (phone/tablet)

Open the viewer URL printed by npm start (it includes ?token=…) on a device on the same Wi‑Fi.
